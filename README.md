# 小孩外出攜帶清單

兩個小孩出門旅行的打包清單。回答幾個問題，自動產生這次要帶的東西。

## 功能

- **情境問答** — 誰要去、去幾天、游泳、火車／高鐵、英文課，依答案篩選項目
- **自動算數量** — 衣服 = 天數 + 1 套（多帶一套備用），睡衣睡褲一天一套
- **兩個小孩分開打勾** — 各自的清單和進度分開計算，共用品只算一份
- **名字可改** — 改 `index.html` 裡的 `KIDS` 就能換成自家小孩的稱呼和注音
- **注音** — 依教育部標法逐字標注（四聲在末符號右上角、輕聲在上方），右上角可開關
- **圖示** — 每個物品前面有 emoji，還不太會認字時也找得到東西
- **出行記錄** — 送出後留存這次帶了什麼，下次可回頭參考

## 使用

打開 `index.html` 即可，沒有任何相依套件。資料存在瀏覽器的 localStorage，
清單進度和出行記錄都只留在自己的裝置上，不會上傳。

## 項目狀態

| 樣式 | 意義 |
|---|---|
| 一般項目 | 要帶的東西 |
| 橘色左線內縮 | 子項目（刷頭、充電線這類配件）|
| 藍色左線 | 待辦提醒（出門前裝滿水、確認狐狐有帶到）|
| `×3` | 依天數計算的數量 |
| `共用` | 兩人共一份，只算一次 |
